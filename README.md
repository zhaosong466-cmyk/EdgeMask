# EdgeMask · 对称黑边

一个轻量 Android 屏幕遮罩工具：在屏幕左右显示对称黑条，自定义可见区域的四角圆角。

**AI 编写声明：本项目的初版源码、APK 构建和项目说明由 ChatGPT / Codex 根据用户需求生成。** 已通过编译、打包和 APK 签名校验，尚未进行真机测试。

## 功能

- 每侧黑条宽度可调为当前屏幕宽度的 0–25%，左右同步。
- 四角圆角半径可调 0–160 dp，自动限制到屏幕能容纳的范围。
- 滑块实时调整，支持 ±1 微调与恢复默认。
- 参数保存于本机，横竖屏自动适配。
- 提供无障碍遮罩和普通悬浮窗两种模式。
- Android 8.0 及以上，无需 Root；原生 Java，无第三方运行时依赖。

## 安装与使用

下载仓库中的 [EdgeMask-1.0.apk](apk/EdgeMask-1.0.apk)，安装并打开：

1. 授予所选模式对应的权限。
2. 选择无障碍模式或普通悬浮窗模式。
3. 点击“启用遮罩”，调整宽度与圆角。
4. 在应用内点击“关闭遮罩”；普通悬浮窗也可从通知栏关闭。

| 模式 | 权限 | 触摸行为 |
| --- | --- | --- |
| 无障碍遮罩（推荐） | 开启“对称黑边 · 无障碍遮罩”服务 | 触摸穿透 |
| 普通悬浮窗 | 允许在其他应用上层显示；通知权限用于显示控制通知 | 黑条与四角方块范围内拦截触摸，中央区域正常操作 |

切换模式会先停止遮罩，需要重新点击启用。无障碍服务不会读取屏幕内容、订阅无障碍事件或执行自动点击；应用没有网络权限。

## 注意

遮罩会覆盖原有内容，不会缩放其他应用、改变应用布局或修改实际屏幕分辨率。系统安全页面可能隐藏悬浮窗，系统栏覆盖效果由 Android 版本和 ROM 决定。手势导航、锁屏及厂商后台管理需要真机验证。

如权限页面无法操作，先关闭遮罩。若 Android 提示“受限设置”，在应用信息页按系统提示允许后再开启无障碍服务。小米 / HyperOS 如果后台停止显示，可检查应用的后台运行设置。

## 构建

使用 Android Studio 打开项目，或安装 JDK 17、Gradle 8.9、Android SDK Platform 35 后执行：

```bash
gradle :app:assembleDebug
```

输出：`app/build/outputs/apk/debug/app-debug.apk`。重新构建的 APK 使用自己的签名，可能需要卸载现有 APK 后安装。
